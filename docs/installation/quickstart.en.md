# Quickstart — Forge Doctor Data (EN)

Three commands:

```bash
git clone <forge-doctor-data>
cd forge-doctor-data
./setup.sh        # Windows: .\setup.ps1
```

Then, from any project:

```bash
forge-doctor-data scan .
```

## Boundary hardening

- **MCP** — 53-test hostile suite; fixes for unconstrained `changes`/
  `manifest` path args, malformed `params`/`arguments` crashes,
  `load_pack_ref` traversal, deep-JSON loop kills; malformed envelopes
  normalize to `-32602`/`-32700`.
- **Plugins** — 53-test hostile suite; bounded-drain capture (unbounded
  memory read fixed), file-claim confinement, describe-row validation,
  argv bounds; runner converts contract breaches to internal-error
  findings instead of crashing.
- **What-if/migration** — byte-identical determinism, no-mutation,
  exhaustive concept-registry sweep: missing evidence or declared gaps
  never yield `DIRECT`; readiness verdicts with counted unknown budgets.
- **§12-18** — corrupt-snapshot `ValueError`, streaming readers,
  retention/compaction, pack provenance statuses, traversal-safe pack
  loading, `ScanRequestError` on bad paths, severity-first `bounded()`,
  `evidence_refs` resync, write confinement proofs.

## Experimental surfaces

- What-if evaluation and migration planning are advisory (`what_if`,
  `migrate_plans`) — deterministic, non-mutating, but the change-target
  vocabulary is narrow (`glue`, `iceberg`, `databricks`, `lambda`,
  `emr`, `platform`).
- `--incremental` scan paths and the runtime-evidence collectors are
  younger than the scan core; they are tested but not yet
  adversarially reviewed at the MCP/plugin depth.
- External plugins via entry points work behind the trust gate; the
  ecosystem contract is `forge-doctor-data`-specific until the
  cross-doctor program lands.

## Validated scale

Measured with `tools/benchmarks/fleet.py` (seeded synthetic workspace,
offline; every artifact carries its own environment block):

```text
validated scan envelope = 250 repos
validated merge envelope = 500 repos
```

- scan n=250: cold p50 641.6ms/repo (p95 3048.5), warm 445.0ms,
  peak 12.1MB, wall 360.6s — `docs/benchmarks/fleet-scan-n250.json`
- merge n=250: 1503 entities / 1001 edges, 24.7s, 12.2MB peak
- merge n=500: 3003 entities / 2001 edges, 40.6s, 2.9MB peak —
  `docs/benchmarks/fleet-merge-n250-n500.json`

n=1000 is **not proven** and is claimed nowhere.

## Upgrade notes (0.9.0 → 1.0.0-rc1)

- `api.scan` and every frontend now raise `ScanRequestError` on a
  missing or non-directory path — previously a plausible report was
  returned for nonexistent roots.
- `HandoffBundle.bounded()` keeps findings severity-first; the kept
  *set* may differ from list-position order under truncation.
- `agent_context` finding rows order error>warning>info (was
  alphabetical); `evidence_refs` enumerate surviving rows only.
- `load_pack`/`load_pack_ref` reject traversal segments.
- No wire-schema changes: all 20 published schemas match the
  `docs/schema-freeze.json` digests.

## Known limitations

- **Fleet beyond the validated envelope is unproven** — scan >250,
  merge >500 have no measured evidence.
- **Plugin ecosystem still evolving** — the SDK is frozen but the
  third-party plugin landscape is not yet exercised.
- **What-if edge cases** — the change-target vocabulary is fixed;
  compound changes and target-specific semantics outside the five
  domains + `platform` return explicit `unknown` entries rather than
  guesses.
- **No automatic cloud access by design** — all evidence is committed
  files; runtime facts arrive only via explicitly supplied execution
  artifacts (offline guarantee preserved).
- **Windows/macOS validated via CI smoke**, full unit matrix runs on
  Ubuntu 3.11–3.13 — heavy benchmarks run on the scheduled gate.
